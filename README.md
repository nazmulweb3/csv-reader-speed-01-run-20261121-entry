A fast drop-in for make.fun's csv-reader 1.0.0 that answers exactly as it does on every case, including broken rows: quoted fields with embedded line breaks, stray CRs, quote junk, unterminated quotes, and ragged rows. Plain records are split with indexOf and slice instead of one character at a time, and quoted fields are consumed a whole segment at a time up to the next quote, so the common case runs far faster than the character-at-a-time reference.

## Run it

```sh
node main.ts
```

Reads `/input/cases.json` and writes `/output/answers.json`. Outside the sandbox, point it at your own directories:

```sh
MAKEFUN_INPUT_DIR=./input MAKEFUN_OUTPUT_DIR=./out node main.ts
```
